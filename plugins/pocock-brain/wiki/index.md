## Principles (16)

- [Fundamentals matter more with AI](principles/fundamentals-matter-more-with-ai.md): AI raises the stakes on classic engineering; old books apply harder to agents. (19 quotes)
- [Code is cheap; maintenance is not](principles/code-is-cheap-maintenance-is-not.md): Writing code got cheap; reading, reviewing and maintaining it did not. (18 quotes)
- [The codebase is the agent's environment](principles/the-codebase-is-the-agents-environment.md): Codebase and harness shape agent output more than prompt or model. (18 quotes)
- [Humans own the strategy](principles/humans-own-the-strategy.md): Agents do tactics; thinking, decisions and the long view stay human. (20 quotes)
- [Alignment before code](principles/alignment-before-code.md): Misalignment is the main failure mode; reach a shared design concept first. (18 quotes)
- [Context is a scarce budget](principles/context-is-a-scarce-budget.md): Quality drops as context fills; work inside the smart zone. (21 quotes)
- [Less is more](principles/less-is-more.md): Delete instructions, docs and complexity until only what changes behaviour remains. (25 quotes)
- [Deterministic over probabilistic](principles/deterministic-over-probabilistic.md): Checks, hooks, workflows and scripts over model judgement and prose rules. (22 quotes)
- [Feedback is the speed limit](principles/feedback-is-the-speed-limit.md): Fast, reliable feedback limits how fast agents, learners and content can go. (19 quotes)
- [Never trust an LLM](principles/never-trust-an-llm.md): Model output is a hypothesis until a source or evidence confirms it. (17 quotes)
- [Communication and shared language](principles/communication-and-shared-language.md): Communicating intent and a shared vocabulary are how understanding happens. (21 quotes)
- [Own the process](principles/own-the-process.md): Small, local, hackable tools over frameworks that take control; technique over tool. (18 quotes)
- [Teacher, not pundit](principles/teacher-not-pundit.md): Teach what works now, give it away, avoid hype and predictions. (22 quotes)
- [Learning at the edge](principles/learning-at-the-edge.md): Pitch learning in the zone of proximal development, along a path of prerequisites. (20 quotes)
- [TypeScript is JavaScript with types](principles/typescript-is-javascript-with-types.md): TypeScript is for tooling: a thin, inferred, pragmatic layer over JavaScript. (22 quotes)
- [Revise in public](principles/revise-in-public.md): Strong opinions, openly reversed and marked when they change. (21 quotes)

## Methods (16)

- [Grilling](methods/grilling.md): The agent interviews him down the design tree before any code. (25 quotes)
- [The main flow](methods/the-main-flow.md): Grill, spec, tickets, implement, review, retro; day shift and night shift. (25 quotes)
- [TDD at agreed seams](methods/tdd-at-agreed-seams.md): Red-green, one test at a time, at seams agreed with the human. (21 quotes)
- [Deep modules](methods/deep-modules.md): Design the interface, delegate the implementation; grey-box modules. (18 quotes)
- [Prototype to answer a question](methods/prototype-to-answer-a-question.md): Throwaway code aimed at one question, especially questions of taste. (20 quotes)
- [AFK loops](methods/afk-loops.md): Unattended agents over a ticket queue: fresh context, sandboxed, reviewed. (19 quotes)
- [Review and retro](methods/review-and-retro.md): Standards live in the reviewer; review scales with risk; mistakes become checks. (23 quotes)
- [Context hygiene](methods/context-hygiene.md): One task per session, token meter, clear by default, deliberate handoffs. (16 quotes)
- [Writing for agents](methods/writing-for-agents.md): Short user-invoked skills: leading words, pointers, positive phrasing, pruning. (25 quotes)
- [Diagnosing bugs](methods/diagnosing-bugs.md): Build a tight red-capable loop before any theory, then minimise and hypothesise. (15 quotes)
- [Problem/solution teaching](methods/problem-solution-teaching.md): Problem first, tests as the signal, one thing per lesson in dependency order. (18 quotes)
- [Content strategy](methods/content-strategy.md): Sugar vs vegetables: short problem/solution content, volume, audience questions. (24 quotes)
- [Content production](methods/content-production.md): Improvise and dictate, film first, Work Clean routine, self-built pipeline. (20 quotes)
- [Running the business](methods/running-the-business.md): Free material, products not sponsorships, partner platform, leverage over hustle. (22 quotes)
- [Build your own tools](methods/build-your-own-tools.md): Build and dogfood the missing tool; personal software and an LLM wiki. (20 quotes)
- [Evals as tests](methods/evals-as-tests.md): For LLM apps: evals as unit tests, scored, fed by user data. (17 quotes)
